适用于 ESP32-2432S028R Plus 一体化触屏板。基于 Web Serial 串口通讯协议，免装驱动，打开网页极速刷写。

BAUD RATE 921600 HIGH-SPEED
DISPLAY CONTROLLER ILI9341 SPI (240x320)
INTERFACE CH340 / CP2102 Serial

02 💡 硬件排障与极速自救 (FAQ)
Q1: 点击后串口弹窗中未显示板子端口？
1) 确保连接线为带数据通讯的线缆（非纯充电线）。
2) 确保已安装 CH340 虚拟串口驱动（Windows 10/11 联网通常自动安装）。
Q2: 提示 Connecting 超时，或串口无限报 invalid header / RTCWDT 复位？
100% 解决技巧：按住开发板背面的 BOOT 按键不要松开，用指甲轻点一下旁边的 RST/EN 按键，再松开 BOOT 键。此时板子将强制锁死在 Bootloader 烧录模式，刷新本页面重新点击烧录即可。
Q3: 烧录完成后如何验证？
烧录达到 100% 后，芯片会自动软复位，2 秒内屏幕即亮起播放器主控界面。插上 FAT32 格式 TF 卡拷入 MP3 即可开始畅听。
