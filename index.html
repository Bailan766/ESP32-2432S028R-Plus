CYD Plus 网页刷机工具

v1.2.4

适用于 ESP32-2432S028R Plus 一体化触屏板。基于 Web Serial 串口协议，直接通过浏览器连接板子完成烧录。

主控: ESP32 双核
屏幕: ILI9341 SPI (240x320)
波特率: 921600
接口: Type-C USB-Serial
⚠️ 您的当前浏览器不支持 Web Serial 串口通讯。请使用 Google Chrome 或 Microsoft Edge 桌面版打开此页面。
💡
准备工作：请使用具有数据传输能力的 Type-C 数据线 连接开发板与电脑 USB 口（若提示找不到设备，请检查是否误用了纯充电线）。
1 固件烧录模式
当前浏览器不支持 Web Serial，请使用 Chrome 或 Edge 安全限制：网页刷机必须在 HTTPS 域名或 localhost 下运行

点击上方按钮后，在弹出的串口列表中选中带有 CH340 或 USB-Serial 的设备即可。

2 常见问题排查 (FAQ)
Q: 弹出的串口列表中没有出现板子？
1) 请确认数据线具备数据传输能力，非纯充电线；
2) 电脑需安装 CH340 虚拟串口驱动（通常 Win10/11 联网会自动安装）。
Q: 提示 Connecting 超时，或串口报 invalid header / RTCWDT 复位？
按住开发板背面的 BOOT 按键不要松开，用指甲轻点一下旁边的 RST/EN 按键，再松开 BOOT 键，使芯片进入等待下载模式，然后重新点击烧录。
Q: 烧录完成后如何使用？
烧录达到 100% 后，芯片会自动复位并点亮屏幕进入系统。插入 FAT32 格式 TF 卡并拷入 MP3 即可正常使用。
