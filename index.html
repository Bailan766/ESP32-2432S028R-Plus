CYD Plus 摆烂播放器 网页刷机工具

v1.1.4

适用于 ESP32-2432S028R Plus 一体化触屏板。基于 Web Serial 协议，打开网页直接烧录。

⚠️ 你的浏览器不支持 Web Serial 串口通讯。请使用 Google Chrome、Microsoft Edge 或 Opera 桌面版打开此页面。

（若之前只能充电无串口，说明是纯充电线，需换成能传输数据的数据线）。

2 连接并开始刷入

点击按钮后，在浏览器弹窗中选中带有 CH340 或 USB-Serial 的端口即可自动开始。

💡 常见排查指引 (FAQ)
Q1: 点击后弹窗里找不到板子的串口？
1) 确保连接线是「数据线」，许多手机附赠的线是纯充电线，无 D+/D- 信号线。
2) 电脑需安装 CH340 虚拟串口驱动（通常 Windows 10/11 联网会自动装好）。
Q2: 烧录过程中提示 "Connecting..." 超时失败？
部分批次板子串口复位电路电容容值偏大，可尝试：按住开发板背面的 BOOT 按键不松开，点击连接，看到开始 Erasing/Writing 后再松开手指。
Q3: 刷完之后怎么用？
烧录进度到达 100% 后，ESP32 会自动软复位进入系统。首次开机将在 2.5 秒内自动展示启动画面并进入主屏。插上 TF 卡（格式化为 FAT32）并拷入 MP3 即可开听。
