# Bailan MP3 Player 硬件测试与验收规范 (TEST_PLAN.md)

> **版本**: v0.1.0  
> **适用阶段**: Phase 1 (硬件全通、底层驱动就绪、DEMO 模式与基础播放器验证)

## 一、开箱与无 TF 卡环境测试流程 (DEMO MODE)

本阶段核心原则是：**在未插入 TF 卡的裸板状态下，系统必须能够平滑开机、完整进入 UI、正常交互并不死机**。

### 1.1 开机自检 (Boot & Splash)
- **步骤**: 开发板上电（通过 USB Type-C 连接电脑）。
- **预期现象**:
  1. 板载 RGB 灯先亮起青蓝色（开机提示约 150ms），随后熄灭；
  2. 屏幕背光平滑亮起，展示 **`BAILAN MP3 PLAYER`** 启动画面与加载提示；
  3. 约 0.6 秒后平滑切入主菜单（HOME）。

### 1.2 主界面与 TF 状态检测 (Home Screen)
- **步骤**: 观察主菜单。
- **预期现象**:
  1. 顶部状态栏显示标题 `BAILAN MP3`、实时电池电压（如 `4.15V`）及动态电量小图标；
  2. 中间显示 4 块大卡片：`🎵 Music`、`🕘 Recent`、`📁 Files`、`⚙ Settings`；
  3. 底部横幅清晰标注：**`TF卡: 未检测到 (当前处于演示模式)`**；
  4. 串口监视器输出：`[SD] 未检测到 TF 卡 (系统平滑切入 DEMO 演示与单板开发模式，不阻塞系统运行)`。

### 1.3 虚拟曲目与非阻塞播放器测试 (Player UI)
- **步骤**: 点击主页 `Music` 卡片，进入播放器。
- **预期现象**:
  1. 显示正在播放曲目（如 `01 Demo Song` - 超级马里奥）；
  2. 中部 16 段复古跳动音频频谱随音符频率高低动态跳跃；
  3. 板载扬声器发声，且无破音、底噪；
  4. 板载 RGB 灯随音符频率变幻色彩（低音暖红、中音翠绿、高音青蓝）；
  5. 点击触屏 `||` 暂停：音乐立即停止，扬声器功放完全关断（无底噪啸叫），RGB 灯转为呼吸蓝灯；再次点击 `>` 恢复播放；
  6. 点击 `>|` 切下一首：无缝切入下一首内置旋律（如俄罗斯方块）；
  7. 点击进度条任意位置：时间戳快速跳转。

## 二、硬件专用自检页面测试 (Hardware Test Page)

进入路径：`主页` -> `⚙ Settings` -> `硬件自检 Test`。

| 测试项目 | 触发方式 | 预期表现 | 验证硬件目标 |
| :--- | :--- | :--- | :--- |
| **LCD 色彩** | 页面静态呈现 | 状态栏显示 `[OK]`，右侧红/绿/蓝三色块清晰无反色 | ST7789 VSPI 驱动正常 |
| **功放与音频** | 点击 `[测音频 1s]` 按钮 | 蜂鸣发声 1 秒（880Hz A5 音），1 秒后自动关闭功放静音 | GPIO 4 功放使能 + GPIO 26 PWM 输出正常 |
| **RGB 色彩** | 点击 `[切换色彩]` 按钮 | 每点一次，RGB 灯在 红 -> 绿 -> 蓝 -> 白 -> 灭 之间循环切换 | GPIO 22/17/16 LEDC PWM 控制正常 |
| **TF 卡检测** | 页面静态呈现 | 显示 `NOT FOUND`（未插卡）或 `OK`（插卡状态） | GPIO 18/19/23/5 HSPI 总线正常 |
| **BOOT 实体键**| 按下板载 BOOT 键 | 屏幕文字实时从 `[RELEASED 松开]` 变为绿色的 `[PRESSED 按下]` | GPIO 0 上拉与去抖检测正常 |
| **电池电压** | 页面静态呈现 | 实时显示当前 ADC 数值与换算电压（如 `ADC: 2580 \| 4.15 V`） | GPIO 34 ADC1 采样正常 |
| **实时触摸** | 点击屏幕任意角落 | `XY:(xxx, yyy)` 实时显示触点像素坐标，压力 `RawZ1` 实时读出 | XPT2046 独立软件 SPI 正常 |

## 三、系统服务与稳定性测试

### 3.1 自动息屏与触摸唤醒
- **设置**: 进入设置，将自动息屏时间设为 `30 秒`；
- **测试**: 让设备在播放音乐时静置 30 秒；
- **预期**: 30 秒到达时，屏幕背光完全熄灭，**但扬声器音乐继续平稳播放**；
- **唤醒**: 轻触屏幕任意位置，背光立即点亮恢复显示，且该次触摸不会误触后台按键。

### 3.2 串口诊断报文验证 (115200)
- 打开串口监视器，观察每 10 秒定时输出的遥测报文：
  ```text
  [SYS] Uptime: 30s | Heap: 198420B (Min:192100B) | Batt: 4.15V | TF: 未检测到 | Player: PLAYING
  ```
  确认堆内存水位稳定无持续递减（无内存泄漏）。
