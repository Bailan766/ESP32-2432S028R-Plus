# ESP32-2432S028R Plus 硬件自检项目

## 一、项目概述

这是一个 ESP32-2432S028R Plus 开发板的硬件自检项目，使用 PlatformIO + Arduino 框架开发。

## 二、硬件规格

### 屏幕与触摸 (2.8寸 320x240 横屏)
- **LCD 驱动**: ST7789 (颜色顺序 BGR)
- **LCD 接口 (VSPI)**: SCK=14, MOSI=13, MISO=12, CS=15, DC=2, BL=21, RST=-1
- **触摸 (XPT2046 电阻屏)**: 独立软件SPI, 不占用LCD的SPI总线
  - DOUT/MISO=39, SCK=25, DIN/MOSI=32, CS=33, IRQ=36

### SD卡 (TF卡)
- **独立总线 (HSPI)**: SCK=18, MISO=19, MOSI=23, CS=5

### GPS模块 (GT-U7)
- **接口**: GPS TX 接 GPIO1(RX), 默认波特率 9600
- **注意**: GPIO1 默认也是 USB/CH340 的 TX, UART2 重映射接收 GPIO1
- **供电**: 3.3V (无需升压)

### 其他板载功能
- **音频**: PWM=GPIO26, 功放使能 EN=GPIO4 (高电平有效)
- **电池检测**: ADC=GPIO34
- **RGB灯**: R=22, G=17, B=16 (低电平点亮)
- **按键**: BOOT按键=GPIO0 (低电平有效)

## 三、开发环境

- **IDE**: VS Code + PlatformIO 插件
- **开发板**: ESP32 Dev Module
- **框架**: Arduino
- **上传速率**: 921600
- **串口监视器**: 115200

### 库依赖
- `bodmer/TFT_eSPI@^2.5.43`

### 编译选项
```
build_flags =
    -DCORE_DEBUG_LEVEL=0
    -DBOARD_HAS_PSRAM=0
    -Iinclude
```

```c
#define ST7789_DRIVER

#define TFT_HEIGHT 320
#define TFT_RGB_ORDER TFT_BGR
#define TFT_INVERSION_ON          // 需要开启反色

#define TFT_MISO  12
#define TFT_MOSI  13
#define TFT_SCLK  14
#define TFT_CS    15
#define TFT_DC     2
#define TFT_RST   -1
```

**重要**: TFT_eSPI 库自带的 `User_Setup.h` 需要被项目中的 `include/User_Setup.h` 替换。路径:


## 七、避坑指南

### 1. TFT_eSPI 配置不生效
**问题**: 修改 `include/User_Setup.h` 后编译不生效
**原因**: TFT_eSPI 库自带的 `User_Setup.h` 优先级更高
**解决**: 把项目的 `User_Setup.h` 复制到库目录:
```
.pio/libdeps/esp32dev/TFT_eSPI/User_Setup.h
```
或清理编译缓存:
```
Remove-Item .pio/build -Recurse -Force
```

### 2. 屏幕显示反色
**问题**: 黑色背景变白色，蓝色变黄色等
**原因**: ST7789 驱动在初始化时无条件发送 INVON 命令
**解决**: 在 `tft.init()` 后调用:
```c
tft.invertDisplay(false);
```

### 3. 屏幕旋转方向
- `setRotation(0)`: 竖屏 240×320
- `setRotation(1)`: 横屏 320×240 ✅
- `setRotation(2)`: 竖屏 240×320 (180°)
- `setRotation(3)`: 横屏 320×240 (180°)

### 4. 按钮布局超出屏幕
**问题**: 按钮被截断不显示
**原因**: y坐标 + 按钮高度 > 240
**解决**: 调整按钮 y 坐标，确保 y + height <= 240

### 5. 串口无输出
**问题**: `Serial.begin(115200)` 后无输出
**原因**: GPIO1 与 USB TX 共用
**解决**: 检查 GPS 是否断开，或使用其他串口

### 6. 烧录失败
**问题**: `Could not open COM9`
**原因**: 串口被占用或开发板断开
**解决**: 
- 检查 USB 线是否插紧
- 关闭串口监视器
- 重新插拔 USB
